- Inter: google/fonts/ofl/inter/Inter[opsz,wght].ttf — 047c92f6e2212473dc436020afed689527076d44
- JetBrains Mono: google/fonts/ofl/jetbrainsmono/JetBrainsMono[wght].ttf — aa310be8b717fe3774f9444dd89d5f4101cc6d10

Use font-display: swap. These full upstream fonts are not yet subset or converted to WOFF2; optimize in M4 if required.

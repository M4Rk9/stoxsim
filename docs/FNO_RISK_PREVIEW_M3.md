# F&O milestone 3, slice 1: discovery and risk review

Tracking: #190. This PR extends existing NSE index futures and long options with single-order risk review, atomic baskets and combined expiry payoff. It does not add option writing or broker-equivalent margin.

## User journey
Select underlying and expiry, filter the loaded page by symbol/strike and contract type, select an opening or closing action, enter lots, request a server preview, acknowledge the simulation rules, then submit. Beginner view explains contracts; advanced view adds exact identifiers in the chain. Neither mode bypasses review. Search explicitly covers the loaded page only; pagination remains available independently of filters. Spot, Greeks and open interest are explicitly unavailable.

## Preview contract
Authenticated POST /api/v1/derivatives/preview accepts contractId, action and lots. No wallet, order, position or request-key row is created. Preview and execution share preparation: catalogue lookup, sessions/expiry, position ownership, capacity, fresh provider quote, bid/ask-or-last selection, tick rounding and DerivativeBook calculations. Preview rejects stale data, unsupported option writing, insufficient funds and invalid closes. The order transaction retains its wallet lock and idempotency checks. Execution always revalidates against current state. Single-order preview needs no schema change; basket persistence adds V135. No credential/flag change.

The response includes exact contract, units, price, upfront premium/margin, cash change/remaining cash and close P&L. Opening-lot expiry breakeven is entry for futures, strike plus premium for calls, strike minus premium for puts (unreachable negative levels return unavailable). Long-option maximum loss is premium; long-future loss is full notional assuming a nonnegative index; short-future loss is unbounded. These are incremental order-lot calculations, not combined-position risk.

Web review expires after 30 seconds and resets on quantity/contract changes. Confirmation is a web interaction requirement, not a new server authorization token; the existing order API remains compatible with older clients. A preview is neither a quote lock nor an execution guarantee. An uncertain order retry retains the same idempotency key. No automatic order retry is introduced.

## Honest simulation limits
Fees are zero in the existing simulator, not claimed real brokerage/taxes. Bid/ask spread may affect fill; no additional slippage model. Futures reserve flat 20% margin, without daily cash MTM or forced liquidation. Cash can go negative on close. Expiry uses the verified underlying index close; missing data keeps settlement pending. No physical delivery or early exercise. Existing provider permissions and quote freshness rules remain unchanged. Basket assumptions and transaction semantics are below.

## Validation
Integration coverage: read-only preview, premium/margin versus loss, call/put breakeven, executable side/tick rounding, close P&L, authentication and ownership, invalid lots/actions, stale quotes, sessions and insufficient funds. Existing fill/partial-close/idempotency/expiry tests protect financial behavior.
Browser coverage: discovery filtering, mandatory review/acknowledgement, quantity invalidation, expired review, retry idempotency and mobile overflow. Main desktop/mobile screenshots are synthetic fixtures attached to the browser report. CI results and final review evidence belong on the PR. Native F&O UI and physical Android-device testing are not part of this web slice.

## Atomic baskets and combined payoff
A basket contains 2–4 distinct opening contracts on the same index and expiry. Options are long-only; futures may be long or short. No closing baskets, calendar spreads, multiple underlyings or margin offsets. Drafts are in-memory only. Editing legs invalidates review. Combined review expires after 30 seconds and requires acknowledgement in both web modes.

POST /derivatives/baskets/preview is authenticated and read-only. It validates each leg and total funding/capacity. Required funds sum full option premiums and per-future 20% margins without a hedge discount. Preview numbers cover new legs, not existing holdings. Payoff uses exact piecewise-linear expiry values for nonnegative index levels. Strike boundaries, zero index and tail slope determine bounds; they are not estimated from chart samples. Breakeven roots are rounded to eight decimals and displayed as approximate; zero-P&L intervals are returned explicitly. The chart includes knots and roots, with an accessible numeric table. No Greeks, time-value path, probability or price forecast is implied.

POST /derivatives/baskets/orders validates opening legs, locks the user's wallet and catalogue rows in canonical order, then calls the existing execution service within ONE outer transaction. If any leg fails, all wallet/position/fill/basket changes roll back. Concurrent retries serialize under the wallet lock. The user-scoped request key plus canonical composition fingerprint returns original fills before quote/session revalidation; a changed composition conflicts. Each leg rechecks a fresh quote and funds during execution; quotes may have different observation times and are not a simultaneous market snapshot. No automatic retries or simulated legging are presented as atomic execution.

V135 adds derivative_basket and a nullable basket_id on derivative_fill. Old clients/order flows remain compatible. Account export includes basket records and fill associations; deletion cascades through the existing wallet. Recent fill history labels the basket. Positions still merge by contract and close individually. Expiry settlement remains per-position, so missing settlement data may leave some positions pending. Roll back application images rather than reversing Flyway migrations.

Added tests cover two breakevens, protective futures hedges, unbounded tails and zero-P&L intervals; read-only preview; combined insufficient funds; later-leg rollback; canonical/concurrent request replay; user-scoped keys; auth; invalid composition; account export/deletion; and browser review/expiry/edit/one-request retry behavior. Synthetic mobile/desktop basket screenshots attach to CI. Live provider and native Android acceptance remain separate.

# Provider setup (owner only)
Store real GROQ_API_KEY, CLOUDFLARE_API_TOKEN, OPENROUTER_API_KEY in protected production environment secrets; CLOUDFLARE_ACCOUNT_ID and model/upstream choices as protected environment variables. The existing Gemini key can be reused on a verified unpaid project. Set `FINWIZ_GEMINI_FREE_CAPACITY_CONFIRMED=true` only after account, model, region and data-use checks. Cloudflare token requires account-scoped Workers AI access. All new providers are disabled by default; set matching FINWIZ_*_ENABLED and FINWIZ_*_FREE_CAPACITY_CONFIRMED only after checking account plan, model eligibility, hard spending controls, privacy terms and commercial use. Do not enable paid inference. Do not paste secrets into chats or commit them.
Provisional conservative application caps: Groq 100/day, Cloudflare 50/day, OpenRouter 30/day, Gemini 500/day, global 500/day. Not published service quotas. Validate actual token/neuron and minute caps; lower settings as needed. OpenRouter requires an eligible explicit :free model and an independent provider slug (no Groq, Google or Cloudflare upstream).
Official contracts: https://console.groq.com/docs/openai ; https://developers.cloudflare.com/workers-ai/configuration/open-ai-compatibility/ ; https://openrouter.ai/docs/api/api-reference/chat/send-chat-completion-request ; https://openrouter.ai/docs/guides/routing/provider-selection
Production deployment checks all configured free providers independently and normally requires one complete response. Gemini credentials may be omitted if another provider is configured. Rollback: disable new provider flags and deploy prior known-good app; additive V137 tables may remain. Never delete usage history as part of rollback.

Set FINWIZ_<PROVIDER>_REQUESTS_PER_MINUTE, FINWIZ_<PROVIDER>_TOKENS_PER_MINUTE and FINWIZ_<PROVIDER>_TOKENS_PER_DAY to conservative admission thresholds aligned to each account's actual quotas. Estimates intentionally overcount many prompts, but cannot guarantee provider billing or Cloudflare neuron limits. Check free-only settings and data-use terms in the provider consoles first. The deploy preflight sends one small non-personal educational probe per enabled provider. No probe is run during PR CI. Verify current model and upstream availability before setting flags. When all free candidates report temporary outage or throttling, the production workflow requires an explicit `ACCEPT_FINWIZ_DEGRADED` dispatch input to continue. Configuration, permission, TLS and malformed-response failures cannot use this override. The backend can keep serving unrelated features while Finwiz recovers. The preflight sends zero paid requests.

| Provider | Verify before enabling |
| --- | --- |
| Groq | Actual project/model limits and retention settings. Confirm model license and usage terms. [Limits](https://console.groq.com/docs/rate-limits) · [Data usage](https://console.groq.com/docs/your-data) |
| Gemini | Active project/model quotas, provider billing status, supported regions and age eligibility. The unpaid terms restrict sensitive or personal prompts, and paid service is required for making the API client available to users in the EEA, Switzerland or UK. If the current access model cannot meet the terms, leave the route disabled. [Terms](https://ai.google.dev/gemini-api/terms) · [Limits](https://ai.google.dev/gemini-api/docs/rate-limits) |
| Workers AI | Actual free neuron allocation, provider spending settings and per-model limits. Verify selected model terms. [Pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/) · [Limits](https://developers.cloudflare.com/workers-ai/platform/limits/) · [Data usage](https://developers.cloudflare.com/workers-ai/platform/data-usage/) |
| OpenRouter | A pinned independent `:free` upstream accepting the no-data-collection and zero-price constraints. Verify actual rate limits, upstream retention and model terms. [Free models](https://openrouter.ai/collections/free-models/) · [Routing](https://openrouter.ai/docs/guides/routing/provider-selection) |

Keep both paid inference flags off until the owner approves the separate project and budgets in [cost controls](COST_MODEL.md). A distinct key on the same Gemini project shares the project quota.

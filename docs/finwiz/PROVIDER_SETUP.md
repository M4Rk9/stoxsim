# Provider setup (owner only)
Store real GROQ_API_KEY, CLOUDFLARE_API_TOKEN, OPENROUTER_API_KEY in protected production environment secrets; CLOUDFLARE_ACCOUNT_ID and model/upstream choices as protected environment variables. Existing GEMINI_API_KEY stays unchanged. Cloudflare token requires account-scoped Workers AI access. All new providers are disabled by default; set matching FINWIZ_*_ENABLED and FINWIZ_*_FREE_CAPACITY_CONFIRMED only after checking account plan, model eligibility, hard spending controls, privacy terms and commercial use. Do not enable paid inference. Do not paste secrets into chats or commit them.
Provisional conservative application caps: Groq 100/day, Cloudflare 50/day, OpenRouter 30/day, Gemini 500/day, global 500/day. Not published service quotas. Validate actual token/neuron and minute caps; lower settings as needed. OpenRouter requires an eligible explicit :free model and an independent provider slug (no Groq, Google or Cloudflare upstream).
Official contracts: https://console.groq.com/docs/openai ; https://developers.cloudflare.com/workers-ai/configuration/open-ai-compatibility/ ; https://openrouter.ai/docs/api/api-reference/chat/send-chat-completion-request ; https://openrouter.ai/docs/guides/routing/provider-selection
Production deployment now checks all configured providers independently and requires one complete response. Gemini credentials may be omitted if another provider is configured. Rollback: disable new provider flags and deploy prior known-good app; additive V137 tables may remain. Never delete usage history as part of rollback.

Set FINWIZ_<PROVIDER>_REQUESTS_PER_MINUTE, FINWIZ_<PROVIDER>_TOKENS_PER_MINUTE and FINWIZ_<PROVIDER>_TOKENS_PER_DAY to conservative admission thresholds aligned to each account's actual quotas. Estimates intentionally overcount many prompts, but cannot guarantee provider billing or Cloudflare neuron limits. Check free-only settings and data-use terms in the provider consoles first. The deploy preflight sends one small non-personal educational probe per enabled provider. No probe is run during PR CI. Verify current model and upstream availability before setting flags. If preflight reports no healthy provider, fix configuration instead of bypassing the gate.
